# Lógica_De_Programção
Esta seção reúne atividades e exercícios desenvolvidos em Python durante as aulas de Lógica de Programação, com o professor Roberto Baumgartel.

Atividades desenvolvidas:

- Exercícios de lógica de programação utilizando Python.

- Atividades práticas envolvendo estruturas de repetição.

- Desenvolvimento e versionamento de códigos utilizando Git e GitHub.

- Aplicação de conceitos fundamentais de programação para resolução de problemas.
